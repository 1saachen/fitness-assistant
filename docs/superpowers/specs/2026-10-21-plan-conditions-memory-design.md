# 计划补充回答的持久记忆

用户已要求由模型判断补充信息是否值得保存，适合长期复用的内容持续保留。

复用 FeedbackMemory / FeedbackCoach：长期与当天计划的用户补充先保存为带来源的原文，再由模型整理记忆，最后刷新规划快照并生成计划。该入口只允许更新记忆，不允许教练递归生成其他计划或将回答当作训练完成事实。自动刷新及教练已经分析过的计划调整不重复分析。

模型通过 fact.retention=long_term 标记长期自报信息（就餐习惯、预算、作息等）；普通 fact 仍默认 14 天，pattern 21 天，限制持续到明确解除。长期 fact 在压缩时受保护。保留逐字引文和日期；不把假设或问题文字当作用户事实，不自动覆盖结构化档案。

表单同时提交用户所回答的问题，避免简短回答丢失上下文。相同回答和目标日期使用确定性来源标识以支持幂等重试；记忆失败时明确显示失败并提供原文入口；规划失败不撤销原文或已经提交的记忆。并发写入仍遵守原有快照校验。

验证：长期保留、临时过期、压缩保护、跨计划读取、限制更正、重试幂等、失败保留、上下文传递、自动刷新不重复分析及现有回归。
